# Harness² deferred scope

Status: DEFERRED for initial Guide v1.

An experiment may be proposed only after a useful Guide and reproducible
baseline identify one bounded workflow weakness (for example, lost citation
facts at handoff). A future probe must use a frozen corpus, cases, rubric and
judge. An optimizer may not change policy, the judge, the holdout, source
allowlist, refusal boundary or model tools, and must not access independent
holdout material through the network. Each run would need exact source/model
identity and proof artifacts.

No optimizer, scheduler, recurring run, training, deployment or experiment is
enabled by this plan.
